# وصلني بطريقك ⚡ — كابتن برو (الإصدار 2.1)

تطبيق الكابتن كامل في **ملف واحد حديث** (`كابتن.html`) — يعمل برفعه مباشرة على أي استضافة
(Firebase Hosting، GitHub Pages، Netlify، أو حتى مجلد محلي عبر خادم بسيط) **بدون أي أمر بناء
أو تثبيت مكتبات**.

> الملف يحتاج فتحه عبر `http(s)` وليس بالنقر المزدوج (`file://`) لأن المتصفحات تمنع
> وحدات ES والـ Firebase من العمل على `file://`.

## 1) ماذا تغيّر في هذا الإصدار؟

### أ. إصلاح أعطال كانت تُوقف التطبيق بالكامل
النسخة السابقة كانت تحتوي تلفًا في الأحرف يمنع عمل الكود:

| العطل | العدد | النتيجة قبل الإصلاح |
|---|---|---|
| استبدال علامة القالب `` ` `` بحرف غير مرئي (U+2060 WORD JOINER) | 54 موضعًا | كل الـ template literals معطوبة ⇒ **خطأ SyntaxError وإيقاف السكربت كاملًا** |
| استبدال `*` في CSS بـ `￼` (U+FFFC) | 1 | تعطّل قاعدة `box-sizing` لكل العناصر |
| فقدان عامل المقارنة في `where("captainPhone", "", phone)` | 2 | فشل استعلام الإحصائيات (كان يُبتلع بصمت داخل `try/catch`) |

تم إصلاح الثلاثة، ولم يعد في الملف أي حرف معطوب.

### ب. تحديث الأدوات (مع سلاسل احتياطية)
- **Firebase SDK**: ترقية من `10.8.0` إلى `12.19.0` (الأحدث) مع **سلسلة تراجع تلقائية**
  `12.19.0 → 11.10.0 → 10.8.0` إذا فشل تحميل إصدار.
- **تخزين دائم (IndexedDB Persistent Cache)**: التطبيق يفتح ويعرض بياناتك **بدون إنترنت**،
  وأي عملية تُنفَّذ أثناء الانقطاع **تُزامَن تلقائيًا** عند عودة الاتصال.
- **Leaflet 1.9.4** مع ثلاثة مصادر CDN بديلة (unpkg → jsdelivr → cdnjs) وبديل لبلاطات الخرائط.
- **OSRM** مع خادم توجيه بديل وذاكرة تخزين مؤقت للمسارات و`AbortController` لإلغاء الطلبات البطيئة.
- واجهة حديثة: متغيرات تصميم (Design Tokens)، وضع داكن/فاتح/تلقائي، زجاجية (Glassmorphism)،
  رسوم SVG مبنية داخليًا (بلا مكتبات رسوم)، حركات وانتقالات، دعم `dvh` و`safe-area` و`prefers-reduced-motion`.
- تقنيات متصفح حديثة مستخدمة فعليًا: Wake Lock (إبقاء الشاشة مضاءة أثناء الرحلة)، Web Share،
  Notifications API، BroadcastChannel (مزامنة التبويبات)، IntersectionObserver، Intl، Viewport Units.

## 1.5) الإصلاحات العاجلة (الإصدار 2.1) — الدخول/الخروج، الخريطة، الاستجابة

### أ. تسجيل الخروج + صفحة دخول/حساب جديد (كانت لا تظهر)
**السبب الجذري:** `loadSession()` كانت تُنشئ **جلسة تجريبية تلقائيًا** متى غاب `cap_session`،
فأي خروج followed بتحميل الصفحة كان يُنشئ جلسة جديدة فورًا ⇒ التطبيق لا يصل لشاشة الدخول أبدًا،
و**لم يكن هناك شاشة دخول أصلًا** داخل الملف.

ما تم عمله:
| العنصر | التفصيل |
|---|---|
| `#auth` | شاشة كاملة لتسجيل الدخول + إنشاء حساب (تبويبان) داخل `كابتن.html` مباشرة |
| بوابة الإقلاع | `boot()` يتوقف عند `loadSession()` إذا لم توجد جلسة، ويعرض `Auth.show()` بدل إكمال التهيئة |
| `Auth.signup()` | تحقق من الحقول، تشفير كلمة المرور (SHA-256 + ملح عبر `crypto.subtle`، وبديل `fnv` لـ `file://`)، حفظ في `cap_accounts_v1`، وكتابة مستند `captains/<phone>` بحقلين إضافيين فقط `authHash` و `authSalt` |
| `Auth.login()` | تحقّق محلي، ومع غياب الحساب المحلي يتحقق من `authHash` في Firestore ⇒ **دخول من جهاز آخر بنفس الرقم**، ورقم مسجّل لدى الإدارة بلا كلمة مرور يُوجَّه لتعيين واحدة مع بياناته القديمة (دمج بدون حذف) |
| `Auth.logout()` | إيقاف الرادار/الـGPS/الوردية/مؤقت الإقلاع + `DB.unsubscribeAll()` + `WakeLock.release()` + تفريغ الطبقات، ثم **إظهار شاشة الدخول فورًا بدون إعادة تحميل** |
| حماية | `saveSession()` لا يكتب بعد الخروج، ولقطة السحابة تُتجاهل، واختصارات لوحة المفاتيح معطّلة داخل شاشة الدخول |
| توافق | مفتاح الجلسة `cap_session` و**كل أسماء الحقول القديمة** كما هي ⇒ ملف التسجيل الخارجي يعمل، والانتقال للتطبيق لا يكسر أي سجل. زر «🧪 وضع التجربة» يبقي السلوك القديم (حساب تجريبي) لمن يريده صراحةً |
| إضافات | «نسيت كلمة المرور؟» بمطابقة رقم اللوحة، «ابقني مسجّلًا» (تذكّر آخر رقم)، إظهار/إخفاء كلمة المرور، وتبديل المظهر من شاشة الدخول |

### ب. الخريطة كانت لا تتحرك وغير واضحة
| المشكلة | الإصلاح |
|---|---|
| `#app` (طبقة الواجهة الشفافة فوق الخريطة) كانت تبتلع كل اللمس ⇒ **لا سحب ولا تكبير** | `#app { pointer-events: none }` + `#app > * { pointer-events: auto }` + تمرير اللمس من فراغات الأوعية العائمة (topbar/hud/fab/cta/map-zoom) |
| لا `touch-action` على حاوية الخريطة | `#map, .leaflet-container { touch-action: none }` |
| `direction: rtl` يُفسد حسابات السحب في Leaflet | `#map { direction: ltr }` مع `direction: rtl` داخل النوافذ المنبثقة فقط |
| الوضع الليلي كان يعتمد **فلتر عكس ألوان** على بلاطات OSM ⇒ خريطة معتمَة/بنفسجية | استخدام بلاطات **CARTO داكنة حقيقية** عند المظهر الداكن، والفلتر العكسي أصبح احتياطًا فقط عند تعذّر CARTO (`data-map-style="invert"`) |
| حجاب `.map-veil` يغطي الشاشة بتدرّج كثيف | استُبدل بشريط خفيف أعلى/أسفل الشاشة فقط (٣٤٪ عتامة بدل ٥٥–٧٢٪) |
| بلاطات ضبابية على شاشات آيفون/آيباد | `detectRetina: true` + `keepBuffer: 4` + `updateWhenIdle: false` |
| الخريطة لا تُعيد القياس عند الدوران/تغيير الحجم ⇒ مربعات رمادية | `invalidateSize` على `resize` و`orientationchange` (مرتين) و`visualViewport` وتغيير القسم |
| لا أزرار تكبير (كانت مخفية بـ `display:none`) | زرّا ＋/− زجاجيان بمحاذاة الخريطة + `zoomSnap: 0.25` و`inertia` مضبوطة و`bounceAtZoomLimits: false` و`maxZoom: 20` |
| التمركز التلقائي يقفز الخريطة أثناء السحب | زر 🧲 «تتبّع» يوقف/يشغّل `autoRecenter`، ويُعلَّق تلقائيًا ١٢ ثانية بعد أي لمس |
| تعذّر تحميل الخريطة بلا أي رسالة | شريط «⚠️ الخريطة لم تُحمَّل» + زر **إعادة المحاولة** (`map-retry`) ومصدر بلاطات بديل تلقائي |
| تغيير النوع كان من الإعدادات فقط | زر 🗺️ على الخريطة يفتح (شوارع/داكن/فاتح/قمر صناعي) فورًا |

### ج. التجاوب مع كل الأحجام (جوّال / آيباد / لابتوب)
- **أساس مرن:** `clamp()` لأحجام الخط، متغيّر `--content-max`، و`--shell-pad`، مع `-webkit-text-size-adjust: 100%`.
- **منع تكبير iOS:** على شاشات اللمس تُرفع خطوط الحقول إلى `16px` (كانت ١٢٫٥ ⇒ المتصفح يقرّب الصفحة عند التركيز).
- **`touch-action` و`interactive-widget=resizes-content`:** اللوحة لا تقصّ المحتوى، والحقل المركَّز عليه يُمرَّر لمنتصف الشاشة (`focusin` + `visualViewport`).
- **نقاط الانكسار:** `≤330px` (طيّات/SE: إخفاء أسماء التبويبات) · `≤360px` (أزرار وباعدات أصغر) · `≥640px` (توسيط الأرفف) · `700–1023px` (آيباد: أعمدة أكثر) · `≥1024px` (سطح المكتب: **شريط جانبي** بدل السفلي، لوحة محتوى بعرض ٤٦٪ على اليمين، والخريطة تملأ البقية) · `≥1360px` و`≥1700px` (أوسع) · `≤560px` أفقي (صف أزرار أفقي) · `(pointer: coarse)` (أهداف لمس ≥46px) · `prefers-contrast` و`prefers-reduced-motion`.
- **الأمان الجغرافي:** كل التخطيط يستخدم `dvh`/`safe-area`/`env()`، والشاشة تدور دون قصّ أو تداخل.

### د. اختبارات التحقق
خُضعت التعديلات لاختبارات آلية في Node بـ DOM وهمي و**Leaflet وهمي يسجّل الاستدعاءات**:
- `28/28` منطق الحسابات (توحيد الأرقام العراقية، التجزئة والتحقق، إنشاء/تكرار/دخول، حماية ما بعد الخروج، وضع التجربة).
- `46/46` الخريطة + الاستجابة (خيارات السحب/التكبير، بلاطات داكنة بلا فلتر، `detectRetina`، `invalidateSize` عند الدوران، تمرير اللمس من `#app`، نقاط الانكسار).
- `33/33` الإقلاع الشامل (بلا جلسة ⇒ شاشة دخول، مع جلسة ⇒ إقلاع كامل، خروج ⇒ عودة لشاشة الدخول، أزرار الشاشة، لا استثناءات JS).
- فحص بنية الملف: أقواس CSS متوازنة، لا وسوم غير مغلقة، لا معرفات مكررة، لا أحرف تالفة (U+2060/U+FFFC/U+FFFD = 0)، وكل `data-action` له معالج.

### قواعد أمان مقترحة (Firebase → Firestore → Rules)
التطبيق الحالي يعتمد على قواعد مفتوحة. إن أردت تقييدها لاحقًا دون كسر التطبيق:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /trips/{id} {
      allow read: if true;
      allow write: if true;   // يكتبها تطبيق الزبون والكابتن
    }
    match /captains/{phone} {
      allow read: if true;
      allow write: if true;
      match /{sub}/{doc} {           // ledger, shifts, notifications
        allow read, write: if true;  // يمكن تقييدها لاحقًا بالمصادقة
      }
    }
    match /supportTickets/{id}  { allow read, write: if true; }
    match /withdrawals/{id}     { allow read, write: if true; }
  }
}
```

## 4) ملاحظات تشغيلية مهمة

- **إضافة التطبيق للشاشة الرئيسية**: من قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية» (يعمل كـ PWA).
- **إذن الموقع**: مطلوب لعمل الرادار بدقة. إن رُفض، يظهر تنبيه ويُستخدم موقع تقريبي.
- **الأرقام**: تُعرض بأرقام لاتينية (`ar-IQ-u-nu-latn`) كما هو معتاد في التطبيقات العراقية.
- **الوضع المحلي**: عند انقطاع السحابة يستمر التطبيق بالعمل من الذاكرة المؤقتة،
  وتُحفظ العمليات وتُزامَن تلقائيًا (يظهر مؤشر «بانتظار المزامنة»).
- **وضع المحاكاة**: من `المزيد ← الإعدادات ← وضع المحاكاة`. الطلبات التجريبية تحمل وسم
  `🧪 محاكاة` ولا يُكتب أي منها في `trips`.
- **التشخيص**: `المزيد ← التشخيص ← فحص شامل` يعطيك تقريرًا فوريًا عن أي مشكلة
  (صلاحيات، قواعد أمان، حظر شبكة، GPS…). انسخ السجل وأرسله للدعم.
- **اختصارات لوحة المفاتيح** (سطح المكتب): `O` تشغيل/إيقاف الرادار، `M` الخريطة،
  `R` التقارير، `C` توسيط الموقع، `Esc` إغلاق النوافذ.

## 6) هيكل الملف (للتطوير)

الملف مقسّم داخليًا إلى طبقات مرقّمة بتعليقات واضحة ليسهل التعديل:

```
[1] الإعداد والثوابت (APP, firebaseConfig, CDN sources)
[2] تحميل المكتبات (سلاسل احتياطية)
[3] الأدوات العامة (تنسيق، تواريخ، جغرافيا، تخزين، اهتزاز، صوت، إشعارات، تصدير)
[4] نظام الواجهة (Toast, Sheets, Modals, Confirm/Prompt, UI components)
[5] الحالة والإعدادات والجلسة (State, Settings, cap_session, Cache)
[6] طبقة قاعدة البيانات (DB, Queue)
[7] الخريطة والموقع والمسارات (MapView, Routes, Geo)
[8] الرادار ودورة الرحلة (Radar, Online, Shared, TripPanel, Trip, Shift, Sim, SOS)
[9] الرسوم والتحليلات + رحلاتي + التقارير (Charts, Analytics, HistoryView, ReportsView)
[10] المحفظة، الأوسمة، المزيد، والأقسام الفرعية، الإعدادات، التشخيص، التوجيه، والإقلاع
```

**الواجهة البرمجية للتصحيح** (من كونسول المتصفح):
```js
CaptainApp.State          // الحالة الكاملة
CaptainApp.DB             // طبقة قاعدة البيانات
CaptainApp.Sim.inject()   // حقن طلب تجريبي فورًا
CaptainApp.Diagnostics.entries()
```
